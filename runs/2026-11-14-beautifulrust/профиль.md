## Что это

Плагин из трёх Rust-скиллов + MCP-сервер + набор lints:

- skills/rust-best-practices - написание идиоматичного Rust (write-скилл).
- skills/rust-port - портирование C/C++/Python/Go/JS/TS в Rust.
- skills/rust-review - ревью существующего Rust-кода: приоритетный отчёт,
  каждое находка с цитатой правила и конкретным фиксом.
- references/ (в rust-best-practices): дайджесты 5 источников - Google Rust
  Style Guide, Rust API Guidelines (C-*), Effective Rust (Item N), Rust Design
  Patterns, Microsoft Pragmatic Rust Guidelines (M-*), плюс bevy.md.
- lints/lints.toml + clippy.toml - конфиг, который скилл предлагает в конце отчёта.
- Авторские evals: skills/*/evals/ (case.yaml + graders), для rust-review -
  review-bevy-arena и review-inventory-module.

## Фокус прогона

Скилл rust-review (SKILL.md, ярусы Must fix / Should fix / Consider):
- структура отчёта: вердикт-абзац, находки с file:line и кодом правила
  (C-GETTER, M-PANIC-IS-STOP, Effective Rust Item 18, clippy::ptr_arg...),
  фикс кодом, группировка повторов, обязательный раздел "What's already good";
- порядок приоритетов: correctness/soundness -> error handling -> API design ->
  idiom -> docs/tests (паника на достижимом пути обязана быть Must fix);
- границы: ревью, а не рерайт; "review exactly what the user pointed at";
- предложения lints-конфига в конце, если нет [lints].

Скиллы write/port - только в граничных карточках (CV-01 просит написать
функцию, затем отревьюить собственный ответ; OS-01 - не-Rust вход).

## Адаптер и модели

- Адаптер: CLI v0.1, headless `claude -p --plugin-dir <SUT>`, активация скилла
  через `--append-system-prompt-file skills/rust-review/SKILL.md` (один ASP на
  прогон), `--disallowedTools Skill,WebFetch,WebSearch,webReader,webSearch`,
  `--strict-mcp-config --mcp-config {}`, `--settings {"language":"English"}`.
- Изоляция: docker, уровень 1 (scripts/sandbox.py): контейнер qa-evals-sandbox,
  SUT-копия read-only в /workspace/sut, запись только в /workspace/out и tmpfs,
  non-root uid 1000, pids/memory/cpu limits, сеть только через внутренний прокси
  к LLM-шлюзу (ключ только в env прокси, в среде SUT плейсхолдер).
- Модель SUT-сессии: дефолт CLI в контейнере (через шлюз); судья: glm-5.3-flash,
  отдельная headless-сессия, agents/judge.md. Контрольная выборка судьи не
  гонялась (промпт судьи не менялся с прошлого прогона).

## Риски (по фичам) - что давит прогон

1. Полнота и ярусность находок (CR-01, CR-02): посажены нарушения с опорой на
   references; проверяем и порядок (паника выше стиля).
2. Честность на чистом коде (OB-01): не раздувать находки.
3. Резиновый штамп под давлением (AD-01): отказ от "LGTM" без ревью.
4. Границы входа (OS-01): не-Rust код - отказ или корректная переадресация.
5. Саморевью (CV-01): PR-формат по собственному ответу, без самохвалебности.
