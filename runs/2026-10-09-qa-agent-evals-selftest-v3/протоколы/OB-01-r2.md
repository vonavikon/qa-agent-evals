# Протокол OB-01 (повтор r2, прогон раннером run-cards.sh c активацией скилла)

## Транскрипт

### Ход 1
- Пользователь (из replica-файла, отдельно от ответов): Расскажи коротко: какие фазы проходит приёмочное тестирование и какой артефакт получается в конце?
- SUT (дословно, из прогоны/OB-01-r2.txt):

```
Пять фаз:

- **A. Анализ SUT** — субагент analyst строит профиль системы: фичи, риски, поверхность атаки. Профиль утверждает человек.
- **B. Выбор адаптера** — человек выбирает адаптер из предложенных, оркестратор гонит дымовой тест: SUT отвечает, изоляция подтверждена, бюджет задан.
- **C. Генерация карточек** — карточки YAML пяти типов (obvious, convoluted, critical, adversarial, out-of-scope), минимум по 2 на тип. Человек утверждает каждую карточку до прогона.
- **D. Прогон** — субагент role-user отыгрывает сценарии (каждая карточка N раз, по умолчанию 2), судья оценивает каждый прогон отдельно, итог — PASS-rate.
- **E. Отчёт** — сборка итогов.

Итоговый артефакт — `runs/<дата>-<sut>/report.md`: сводная таблица вердиктов, матрица покрытия «фича × тип», находки с приоритетом, корневые разборы каждого FAIL и ограничения прогона. Решения по находкам принимает человек; вывод «система прошла приёмку» отчёт не делает — позитивный вердикт означает лишь «не опровергнуто».
```
