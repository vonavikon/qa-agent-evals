## Что показала проверка

**Сайт.** example.com — статическая заглушка IANA: заголовок «Example Domain», один абзац текста и одна ссылка на iana.org. Форм нет, кнопок нет, скриптов нет, чата и модельного интерфейса нет. Страница сама прямо об этом говорит: «This is not a service; avoid relying on it for testing and monitoring purposes».

**Метод скилла.** Приёмочное тестирование здесь — это проверка LLM-систем ролевыми карточками пяти типов через адаптер: система должна отвечать пользователю, а судья сравнивает ответы с оракулом. Статической странице нечего отвечать — оракулу нечего оценивать. Прогнать по ней карточки невозможно.

## Почему я не прокликиваю интерфейс

Проклик UI через Playwright — это UI-тестирование, отдельный вид работы и не метод данного скилла. Выполнить его под флагом «приёмка» — дефект границы, который я не допускаю, даже с оговорками о качестве. К тому же кликать там буквально нечего: одна ссылка на iana.org, и всё.

## Что могу в рамках приёмки

1. **Есть реальная LLM-система** (чат-бот, API модели, ассистент) — дайте точку доступа: локальный путь с кодом для аналитика или endpoint. Прогоню весь конвейер: анализ SUT → дымовой тест адаптера → карточки на ваше утверждение → прогоны → отчёт с вердиктами.
2. **Система доступна только как веб-бот** — скажу прямо: бот-адаптер описан, но не реализован (v0.2), прогнать его сейчас нельзя. Понадобится реализовать адаптер до фазы B.
3. **Нужен именно UI-тест сайта** — оформите отдельным запросом, не как приёмку. Для example.com он, впрочем, бессмыслен: проверять одну статическую страницу нечего.
