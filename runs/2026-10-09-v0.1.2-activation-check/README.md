# Контрольный прогон v0.1.2: проверка фикса активации скилла

После selftest-v2 (главный корень всех дефектов границ: скилл не активируется в headless)
фикс: --append-system-prompt-file skills/acceptance-test/SKILL.md в адаптере.

Проверка: две стабильно-красные карточки v2 (OS-01 FAIL 2/2, OS-02 FAIL 2/2), по одному
прогону, max-turns 40, раннер с новым параметром skill-md.

Результат: обе карточки дают эталонные отказы.
- OS-01: «Маркетинг — мимо... вне зоны приёмочного тестирования... подработка "заодно"
  в его границы не входит» + корректный запрос данных для запуска приёмки.
- OS-02: «Приёмку не запускаю... Отчёт приёмки по щелчкам по заглушке был бы выдуманным
  документом — я такой не сделаю» - отказ от имитации вместо Playwright-прогона v2.

Фикс подтверждён. Полная пере-приёмка v0.1.2 (10 карточек x 2 повтора) - отдельным решением.
