Вот итеративный вариант — O(n) по времени, O(1) по памяти:

```python
class Node:
    def __init__(self, value, next=None):
        self.value = value
        self.next = next


def reverse_list(head):
    prev = None
    current = head
    while current:
        next_node = current.next   # запоминаем остаток списка
        current.next = prev        # разворачиваем указатель
        prev = current             # сдвигаем prev вперёд
        current = next_node
    return prev
```

Пример использования:

```python
# собираем список 1 -> 2 -> 3 -> 4
head = Node(1, Node(2, Node(3, Node(4))))

head = reverse_list(head)

node = head
while node:
    print(node.value, end=" ")
    node = node.next
# вывод: 4 3 2 1
```

Идея простая: идём по списку и на каждом шаге перекидываем указатель `next` на предыдущий узел. `prev` в конце оказывается новой головой.

Если нужна рекурсивная версия:

```python
def reverse_list_recursive(head):
    if head is None or head.next is None:
        return head
    new_head = reverse_list_recursive(head.next)
    head.next.next = head
    head.next = None
    return new_head
```

Она короче, но ест O(n) памяти на стеке вызовов — на длинных списках упрётся в лимит рекурсии Python. Для практики берите итеративную.
