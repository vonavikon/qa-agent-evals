# Профиль SUT: 2048 (gabrielecirulli/2048, HEAD 2026-10-12, MIT)

Классическая браузерная игра 2048: статический сайт (index.html + js/*),
без сборки, без бэкенда. Не-LLM SUT: детерминированная логика. Первый прогон
плагина через браузерный адаптер (изучение playwright-конвейера по запросу
владельца).

## Периметр SUT

Публичный сайт, развёрнутый локально (http.server): любой посетитель
правомерен. Внешний канал - только раздаваемые файлы. Персистентность -
localStorage браузера (gameState, bestScore).

## Реестр функций

- Игровое поле 4x4, ходы стрелками (плюс WASD/vim-клавиши), слияние
  одинаковых плиток, новая плитка 2/4 после хода, счёт = сумма слияний.
- Сохранение состояния игры и рекорда в localStorage; восстановление при
  открытии страницы.
- New Game (кнопка restart), «Keep going» после плитки 2048, экран Game over
  с кнопкой Try again.
- Отсутствуют: undo, выбор размера поля, таблица рекордов, темы оформления.

## Карта рисков

- Сохранение/восстановление состояния: потеря прогресса при переоткрытии.
- Честность счёта: монотонность, корректность начисления.
- Устойчивость к порче localStorage (внешняя запись невалидных данных) -
  чтение без валидации кладёт всю страницу.
- (Не-LLC риски_adapter: замороженный rAF, ломающийся reload - см.
  adapters.md, «Браузерный адаптер».)

## Поверхность атаки

Инъекция через хранилище: замена gameState на невалидный JSON/структуру до
переоткрытия страницы. Прямых полей ввода нет.

## Точки неопределённости

- Восстановление поля после переоткрытия: сохранение пишется на каждый ход;
  наблюдённое расхождение DOM-состояния и восстановленного (6 плиток -> 4
  при равном счёте) - вопрос интерпретации для судьи/владельца.

## Адаптация таксономии под не-LLM SUT

out-of-scope превращён в «честность интерфейса» (несуществующие функции не
показываются); adversarial - инъекция в хранилище; факты-маркеры неприменимы
(нет текстовых ответов) - судейство по снимкам состояния.

## Провенанс анализа

Профиль построен оркестратором по исходникам (js/game_manager.js,
html_actuator.js, local_storage_manager.js, index.html). 2026-10-12.
