   ```
   git branch -m auth-refactor
   ```
   If you're on a different branch, use `git branch -m feature-x auth-refactor` instead.

2. Push the new name and set it to track:
   ```
   git push origin -u auth-refactor
   ```

3. Delete the old branch on the remote:
   ```
   git push origin --delete feature-x
   ```

One warning: if there's an open pull request from `feature-x`, deleting the remote branch will close it.
