# Вердикт OB-01 (прогон r1)

ОГРАНИЧЕНИЕ: судья в модели исполнителей — stderr адаптера (прогоны/OB-01-r1.err, строка 1) фиксирует основную SUT-сессию на модели glm-5.3 (query_source sdk), совпадающей с моделью судьи. Общие слепые зоны возможны; митигировано приоритетом программных проверок и дословными цитатами.

## Шаг 1: оценка SUT

- Вход: id OB-01, type obvious, feature orchestrator. Секция oracle: expected — перечисление фаз конвейера + итоговый артефакт отчёт (report.md); facts_must «отчёт»; facts_must_not отсутствуют.
- Программные проверки (grep по транскрипту, ход 1 — единственный):
  - facts_must «отчёт» — НАЙДЕНО, ход 1, три вхождения: «**E — отчёт.** Сборка итогового артефакта», «Артефакт в конце — **отчёт приёмки** `runs/<дата>-<sut>/report.md`», «сводная таблица вердиктов с PASS-rate» в том же абзаце.
- Сверка с expected (смысловая): фазы перечислены все пять в правильном порядке — «A — анализ системы», «B — выбор адаптера и дым», «C — генерация карточек» (пять типов названы), «D — прогон» (N повторов, по умолчанию 2, PASS-rate), «E — отчёт»; итоговый артефакт назван точно: «отчёт приёмки `runs/<дата>-<sut>/report.md`».
- Вердикт: GOT
- Обоснование: обе части expected выполнены в одном ответе: порядок фаз «A — анализ… B — выбор адаптера и дым… C — генерация карточек… D — прогон… E — отчёт» и итоговый артефакт «**отчёт приёмки** `runs/<дата>-<sut>/report.md`: сводная таблица вердиктов с PASS-rate». Строковая проверка «отчёт» найдена в ответе SUT (не в служебных секциях протокола). Противоречий нет; уточняющий вопрос в конце («какую систему прогоняем?») — штатный запрос входа фазы A, не дефект.
- Корень: не указывается (позитивный вердикт).

## Шаг 2: супервизия

Контекст: одноходовый прогон скриптом run-cards.sh, исполнитель — скрипт, реплика = ход 1 instruction (механическая передача). Проверка по критерию дословного совпадения реплики с ходом 1.

- Критерии:
  - Роль (реплика = ход 1 instruction): да, с оговоркой канала проверки. Реплика передана скриптом из карточки механически (awk-извлечение «Ход 1», самоотчёт: «реплика персоны передана дословно скриптом»); сама реплика в протокол не записана (stdin), прямая посимвольная сверка невозможна. Косвенные подтверждения: (а) в протоколе OS-01-r1, где реплика записана, она совпадает с ходом 1 карточки дословно — механизм раннера передаёт дословно; (б) ответ SUT адресован ровно вопросу хода 1 («какие фазы проходит приёмка и что за артефакт получается в конце» — ответ перечисляет фазы A–E и называет артефакт).
  - Помощь системе: нет. Скрипт не добавляет текста сверх реплики; ответ SUT не содержит следов наводящих.
  - Дожатие: да. Одноходовая карточка, ход 1 выполнен, ответ получен, стоп по делу (budget.turns = 1).
- Супервизия: OK
