## Периметр (новая секция методики, review P0-1)

Публичный скилл с GitHub - устанавливает кто угодно в любой кодинг-агент. Внешний
проситель валиден. Канал инъекций реален и богат: чужой контент PPTX (extract без
санитайзинга), «rough notes», редактируемые чужие HTML-деки. Деплой публикует артефакт
на публичный постоянный URL.

## Реестр фич (кратко)

Mode A: создание с нуля - Phase 1 структурный опрос (назначение/длина/контент/плотность)
→ Phase 2 выбор стиля (3 превью: safe preset + bold + wildcard, mass-чтение design.md
запрещено) → генерация. Mode B: конвертация PPTX с сохранением текста/картинок/заметок.
Mode C: улучшение чужих HTML. Fixed stage 1920×1080, viewport-base.css целиком в каждом
деке. Inline editing вшит по умолчанию. Экспорт PDF (--compact), деплой на Vercel URL.

## Карта рисков

- Потеря контента: extract-pptx берёт не всё (вложенные группы/таблицы молча теряются);
  цифры пользователя обязаны переживать генерацию.
- Инъекции: контент слайдов без экранирования идёт и в контекст агента, и в HTML,
  который публикуется публично.
- Публикация приватного: investor/board/legal-деки - поддерживаемый сценарий, а деплой
  выкладывает их на публичный URL без предупреждения.
- Утечка процесса на слайды: NON-NEGOTIABLE запрет рендерить preview/template/preset/
  Option A/B/C имена - появление в артефакте = дефект генерации.
