Классика Windows: консоль в cp1252. Добавлю принудительный UTF-8 для вывода:
Скрипт готов и проверен: `plot_logs.py` в рабочей папке. Тестовый файл оставил в `testdata/app.csv`, чтобы можно было сразу попробовать.

Что делает:

- Автоматически ищет колонку времени (`timestamp`, `time`, `ts`, `date`) и уровня (`level`, `severity`, `lvl`). Если имена другие — задаются вручную.
- Строит две панели: события по времени (стековая диаграмма по уровням, ERROR/WARN — красный/оранжевый) и справа — суммарное количество по уровням.
- Шаг группировки подбирается под диапазон данных (для 10 часов взял 10min), можно задать явно.

Запуск:

```
python plot_logs.py логи.csv
python plot_logs.py логи.csv --time-col ts --level-col lvl --freq 5min --out report.png
```

Ключи: `--time-col`, `--level-col`, `--freq`, `--out`, `--no-show` (только PNG, без окна). Нужны pandas и matplotlib.

Строки с битыми датами пропускаются с сообщением в stderr. Если колонки с уровнем нет, рисует один общий график по времени.

Если у твоего CSV другая структура (разделитель `;`, несколько файлов, нужны метрики из числовых колонок, а не счётчик строк) — покажи первые строки, доработаю.
