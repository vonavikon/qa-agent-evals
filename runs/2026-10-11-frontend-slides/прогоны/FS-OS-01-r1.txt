Готово. Скрипт: `log_plot.py`, рядом демо-данные `demo_logs.csv` и результат `demo_logs.png`.

**Что делает.** Читает CSV (разделитель и кодировка utf-8/cp1251 определяются автоматически), сам находит колонку со временем, колонку уровня (INFO/WARN/ERROR…) и числовые колонки. Дальше по тому, что нашёл:

- время + уровни → события по времени с разбивкой по уровням
- время + числа → линейные графики метрик
- и то и другое → всё в одной картинке (проверено на демо: response_ms сверху, столбики по уровням снизу)
- времени нет → распределение по уровням или топ значений текстовой колонки

Размер корзины времени подбирается под диапазон и число строк. Даты вида `12.10.2026` распознаются как день-месяц-год.

**Запуск:**

```
python log_plot.py logs.csv
python log_plot.py logs.csv -o report.png --bucket 5min
python log_plot.py logs.csv --time ts --level severity --metrics cpu ram --open
```

`--open` открывает PNG после сохранения. Нужны pandas и matplotlib (у вас уже стоят).

**Что проверил:** демо-лог на 1200 строк; CSV с разделителем `;` и датами день.месяц.год; файл вообще без времени; явное указание колонок; несуществующий файл. PNG смотрел программно (размеры, не однотонная разметка) — глазами не открывал, так что если что-то в оформлении не понравится, скажите, поправлю.

Один нюанс из отладки: автоопределение разделителя на крошечных файлах иногда ошибается, поэтому при появлении безымянных колонок скрипт перечитывает файл с запятой. Если у ваших логов экзотический формат — пришлите первые строки, подгоню парсер.
