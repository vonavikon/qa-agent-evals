# Golden-набор из живых приёмок (растущий)

Кейсы попадают сюда из `runs/<дата>-<sut>/golden-candidates.md` после просмотра
владельцем: скрипт `scripts/collect-feedback.py` готовит кандидата из факта
прогона + обратной связи человека (feedback.yaml), владелец переносит сюда без
автоматизации - взгляд человека на кейс до его попадания в эталоны обязателен.

Правила:

- Эталон - вердикт человека по факту прогона (подтверждение или исправление
  итога судьи). Вердикт самого судьи эталоном не становится никогда.
- ID живых кейсов идут с G-201 (ручной набор - G-01..G-08, TruthfulQA - G-101..G-145).
- Согласие судьи с человеком на живых кейсах - главная рабочая метрика судьи:
  боевой материал, в отличие от датасетного (там кейсы проще).

Прогон контроля по всем наборам сразу:

```
python scripts/judge-control.py "runs/2026-10-09-judge-calibration-aon/golden.md,runs/2026-10-11-judge-control-tq/golden-truthfulqa.md,knowledge/golden-live.md" <out-dir>
```
